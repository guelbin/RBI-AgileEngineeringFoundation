Why AI Testing Needs a Different Approach

Traditional software testing is built around a simple assumption: the same input should normally produce the same output.

But AI and LLM-based systems do not always behave like that. The result can vary, even if the input looks identical.

That changes how we need to think about reliability, quality and testing.
